# Betwise

Kenya's sportsbook and Pop It casino — live football odds, M-Pesa deposits and payouts.

Live at https://betwiseke.vercel.app/

## Stack

- React 18 + Vite 5 + TypeScript + Tailwind CSS
- TanStack Query, React Router, Framer Motion
- Supabase (PostgreSQL, Auth, Edge Functions, Realtime)

## Development

```bash
npm install
npm run dev
```
